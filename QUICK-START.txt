API ENDPOINTS
=============

1. Get Attendance (Path Parameters)
   URL: GET /api/attendance/employee/{empId}/month/{month}
   Parameters:
     - empId: Employee ID (e.g., EMP001)
     - month: Month format - supports:
       * Full month names: january, february, march, april, may, june, july, august, september, october, november, december
       * Short month names: jan, feb, mar, apr, may, jun, jul, aug, sep, oct, nov, dec
       * Month numbers: 1-12
       * YYYY-MM format: 2026-08
   
2. Get Attendance (Query Parameters)
   URL: GET /api/attendance/search
   Parameters:
     - empId: Employee ID
     - month: Month (any format as above)
   
3. Health Check
   URL: GET /api/attendance/health

EXTERNAL API INTEGRATION
========================
The application calls: http://117.192.9.195/Attendance_Api/punchReport.php

Request Method: POST
Content-Type: application/x-www-form-urlencoded

Parameters sent (in request body):
  - EMP_CODE: Employee ID/Code
  - FROM_DATE: First day of month (YYYY-MM-DD format)
  - TO_DATE: Last day of month (YYYY-MM-DD format)

Example call (cURL):
  curl -X POST http://117.192.9.195/Attendance_Api/punchReport.php \
    -H "Content-Type: application/x-www-form-urlencoded" \
    -d "EMP_CODE=EMP001&FROM_DATE=2026-08-01&TO_DATE=2026-08-31"

HOW IT WORKS
============
1. Client Request
   → GET /api/attendance/employee/EMP001/month/2026-08

2. API Server
   → Receives request
   → Calculates month start/end dates
   → Calls external API with parameters:
     * EMP_CODE=EMP001
     * FROM_DATE=2026-08-01
     * TO_DATE=2026-08-31

3. External API Response
   → Returns JSON with attendance records
   → Example fields: PUNCH_DATE, IN_TIME, OUT_TIME, WORK_HRS, STATUS

4. Response Transformation
   → API transforms external response
   → Calculates statistics (present days, total hours, etc.)
   → Returns standardized JSON format

5. Client Receives
   → Comprehensive attendance summary
   → Day-by-day details
   → Total working hours

TROUBLESHOOTING
===============

Port Already in Use:
  - Change server.port in src/main/resources/application.properties
  - Or kill the process on port 8080

External API Not Reachable:
  - Check network connectivity to http://117.192.9.195
  - Verify firewall settings
  - API returns empty results if external service is down

Build Issues:
  - Ensure Java 17+ is installed: java -version
  - Ensure Maven is installed: mvn -version
  - Clear Maven cache: mvn clean

Cannot Connect to API:
  - Ensure the server is still running (check terminal window)
  - Ensure you're using http:// not https://
  - Check firewall settings
